# OneImg v4.1.3：九项安全边界加固

本版本在保留 API v1、现有权限码、存储类型、批量上传响应结构和历史媒体 URL 的前提下，修复九项安全问题。不整包合并上游，不引入独立媒体服务，也不修改 PicGo 插件源码。

## 安全修复

1. 公共媒体仅允许 GET/HEAD；WebDAV 读取客户端再次限制方法且不跟随重定向，匿名写请求不会到达存储。
2. 新安装生成独立随机初始密码并以 `0600` 落盘。历史 ID 1 默认密码账户进入受限状态，必须提供服务器本地一次性恢复码才能完成恢复；恢复时撤销历史 Passkey。
3. 引用已有存储配置执行连接测试必须具有 `storage:update` 权限；授权先于秘密使用和联网。更换端点或账户时，更新和测试均必须显式提供新凭证。
4. Home/Gallery 共用 Vue 预览组件，以文本和属性绑定渲染动态元数据，移除预览动态 HTML 和内联事件；历史 URL 按路径编码，下载名安全清洗。
5. 禁止新增 SVG 及伪装 SVG。历史 SVG 保留文件和 URL，应用代理设置严格 CSP、nosniff 和重新验证缓存策略，限制脚本、外部资源、表单与嵌入内容。
6. 新主图和缩略图共用 128 位随机对象身份，不再复用同名 key。本地排他创建，S3/R2/WebDAV 条件创建；回滚只清理本次明确创建的对象，删除前检查跨桶及主图/缩略图交叉引用。
7. 在完整解码前校验真实栅格格式和尺寸，默认上限 40,000,000 像素、单边 16,384，全局图像处理并发为 1。普通上传、URL 导入、本地导入和原图模式不能绕过预算；繁忙返回可重试错误。
8. 会话和 PAT 绑定认证版本。改密或管理员重置在事务中递增版本并撤销全部 PAT；旧版本请求不能创建有效的新 PAT。普通改密保留 Passkey，只改用户名不批量撤销 PAT。
9. `TRUSTED_PROXIES` 必须显式配置，默认不信任转发身份；拒绝非法值及全网 CIDR。限流表定期清理且最多保留 10,000 个身份，满表不淘汰有效窗口为新身份腾位。

独立候选补丁审查后，还补齐了存储端点更新与上传/删除的并发协调、multipart 临时磁盘缓存、FTP 登录目录相对路径一致性，以及合法存储更新的配置序列化回归。

## 升级注意

- 升级前备份一致的 SQLite、持久化配置和媒体；在备份副本验证幂等迁移。
- 缺少认证版本的旧浏览器会话失效，需要重新登录。正常历史 PAT 保留；旧默认密码风险账户是例外，其 PAT 会被撤销。
- 未显式设置唯一初始密码时，从数据库同目录 `.initial_admin_password` 读取初始密码；初次登录必须改密。
- 历史 ID 1 账户仍使用 `123456` 时，从数据库同目录 `.admin_recovery_code` 读取本地恢复码。只知道旧默认密码不足以恢复管理权限。
- 改密或重置后，为 PicGo 等客户端创建并配置新 PAT。插件协议未变。
- 反向代理部署必须配置真实入口 IP/CIDR，并在入口覆盖客户端提供的转发头；不自动信任 Docker 或私网网段。
- 禁止新增 SVG 是有意的兼容性收紧。CDN、静态服务器、对象存储直链等绕过应用的出口，必须设置等价 SVG 响应策略并处理旧缓存。
- 默认单实例运行，不让新旧版本同时写同一数据库和存储。进程内对象锁不提供跨实例协调，FTP 写前检查也不是原子条件创建。
- 不恢复旧数据库来撤销已经完成的改密或凭证撤销，否则可能重新激活旧凭证。功能回滚必须保留安全边界。

## 验证范围与发布边界

- 后端全仓测试、竞态检测和 `go vet`，前端类型检查和生产构建，以及 OpenAPI/生成 SDK 一致性检查通过。
- 隔离 Linux 容器内 Chromium、Firefox、WebKit 共 12 项安全回归通过，覆盖恶意历史元数据、预览操作、移动端，以及历史 SVG 的主动内容阻断。
- 正常上传、去重、公开读取、Range、原图、缩略图、动画 WebP、视频和本地导入有回归覆盖。
- ARM64、2 GiB 内存限制的本地运行库中，正常 24MP/40MP 图片处理成功，峰值 RSS 约 225/372 MiB。本次输入的实测值不是最坏输入上界，不能替代目标生产环境复测。
- 测试使用临时 SQLite、本地模拟存储和隔离容器，没有访问生产凭证或生产媒体。真实 S3/R2/WebDAV/FTP 服务的条件创建与失败语义仍需部署方在经授权的隔离存储中验收。

发布源码和镜像不代表已完成每个部署环境的生产验收，也不代表消除所有 DoS 或完成全仓安全认证。详细部署、复测命令及回滚约束见 `docs/security-hardening.md`。
